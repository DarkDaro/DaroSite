# Музыка сайта

Пять инструментальных тем для разделов сайта. Формат MP3, 32 кГц, моно, 64 кбит/с. Каждый файл около 375 КБ, длительность 48 секунд, воспроизведение зациклено. В начале и конце каждого трека плавный фейд 3.2 секунды, последний сэмпл равен нулю.

| Файл | Раздел | Характер |
|---|---|---|
| `rain.mp3` | Главная | Мягкий дождь, тёплый аккорд, редкие капли |
| `paper.mp3` | Библиотека, книга, глава | Тёплая библиотека, щипковые ноты, спокойный бас |
| `industry.mp3` | Мир, досье, локации, организации | Низкий пульс, металлические ноты, редкие удары |
| `neon.mp3` | Галерея | Холодные арпеджио, стеклянные ноты, мерцание |
| `signal.mp3` | Автор | Радиосигнал, короткие бипы, тёплый фон |

Треки собраны скриптом `tools/music.mjs` из аккордов, баса, арпеджио и мелодии. Белый шум не используется. Внешние сэмплы и записи не применяются, сторонние лицензии не нужны. Пересборка: `npm run music`, нужен `ffmpeg` с `libmp3lame`. Если `ffmpeg` не в `PATH`, путь задаётся переменной `FFMPEG`.

## Звуковые эффекты и озвучка

- Эффекты синтезируются на месте через Web Audio API: клик, открытие и закрытие меню, переход, поиск, находка, ошибка, переключатель.
- Отдельных файлов эффектов нет, поэтому сайт остаётся офлайн и не делает сетевых запросов.
- Озвучка экспериментальная и работает через локальный `speechSynthesis` браузера. Кнопки «Озвучить» есть на страницах глав и в досье.
- Если русского голоса в системе нет, браузер использует системный голос с русской локалью. Качество зависит от установленных голосов Windows.
- Кнопка «Звук» в шапке выключает музыку, эффекты и озвучку одновременно.
- Общая громкость задаётся ползунком в блоке `about.html#sound`. По умолчанию 70 процентов, значение хранится в `localStorage` под ключом `sol-volume`.
- Базовые уровни: музыка 0.18, эффекты 0.09, голос 0.6. Ползунок умножает их на общий коэффициент. В сумме уровни остаются ниже единицы.
- На эффекты стоит компрессор с порогом -12 дБ, чтобы короткие сигналы не перегружали выход.
- Проверка звука: `about.html#sound`, ползунок громкости и три кнопки «Проверить музыку», «Проверить эффект», «Проверить голос».

Состояние хранится в `localStorage` под ключом `sol-sound`. Позиция трека и текущий раздел хранятся в `sessionStorage`, чтобы музыка продолжалась при переходе между страницами одного раздела. Если браузер блокирует автозапуск, кнопка подсвечивается и запускает звук после нажатия.
