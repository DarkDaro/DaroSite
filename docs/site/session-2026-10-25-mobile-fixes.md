## Методика

- Chromium через Playwright, ширины 320, 360, 390, 430, 768 px.
- Для якорей включён `prefers-reduced-motion: reduce`, чтобы проверка не зависела от длительности плавной прокрутки.
- Замеры: `getBoundingClientRect`, `scrollWidth`, `clientWidth`, вычисленные `font-size`, состояния `aria-expanded` и `data-open`.
- Полные отчёты: `%TEMP%\solyanoy-mobile-report.json`, `%TEMP%\solyanoy-interactions-report.json`, `%TEMP%\solyanoy-qa-report.json`.
- Скриншоты: `%TEMP%\opencode\mobile-shots\`.

## Результаты

### 1. Таблицы каталогов

- До 900 px таблица имплантатов и вооружения показывается карточками.
- На 320 px карточка равна 292 px, на 390 px равна 354 px, на 768 px две карточки по 348 px.
- Внутренняя прокрутка таблицы отсутствует: `scrollWidth` равен `clientWidth`.
- 8 имплантатов и 7 единиц вооружения выводятся полностью.
- Добавлена мобильная сортировка. Проверка: «Второй контур» меняется на «Гнездо» при сортировке по производителю.

### 2. Фильтры и тулбар

- На 320 px панель `locations.html` уменьшилась с 744 до 173 px, результаты начинаются с 625 px вместо 1196 px.
- `characters.html`: тулбар с 261 до 219 px, результаты с 631 до 642 px. Высота выросла из-за тап-зон 44 px, но список остаётся в первом экране.
- `implants.html`: панель фильтров закрыта, результаты начинаются с 617 px.
- На 768 px панель `locations.html` занимает 129 px, результаты начинаются с 505 px.
- Фильтры до 900 px закрыты по умолчанию, `aria-expanded="false"`, панель открывается и закрывается кнопкой.

### 3. Досье

- Крошки, шапка досье, портрет и тело выровнены по `.wrap`.
- На 320 px все начинаются с x=14, на 390 px с x=18, на 1440 px с x=80.
- Горизонтального переполнения нет.

### 4. Тап-зоны

- Самостоятельные элементы управления не меньше 44 x 44 px.
- Проверка 145 страниц на пяти ширинах: 0 элементов ниже 44 px.
- В шапке на 320 px четыре кнопки по 44 px. Бренд уменьшен до 10 px, страница остаётся в 320 px без горизонтального скролла.
- Вкладки имеют минимум 44 px по ширине и высоте.
- Ползунок громкости 44 px, закрытие меню 44 x 44 px.

### 5. Шапка, якоря и прогресс

- `--header-h` равен фактической высоте шапки: 64 px до 900 px, 74 px на desktop.
- Полоса прогресса начинается ровно на нижней границе шапки: 64 px на мобильной и 74 px на desktop.
- `#contents` на 320 px начинается с 74 px, служебная строка секции с 131 px.
- На 1440 px `#contents` начинается с 84 px, служебная строка с 200 px.
- В интерактивной проверке на 390 px якорь начинается с 82 px, служебная строка с 139 px. Строка не теряется.
