## 5. Найденные разрывы

### 5.1. Издательский слой

| Элемент | Состояние | Вывод |
|---|---|---|
| Логлайн | нет | нужен один короткий абзац для первого экрана и питча |
| Короткий синопсис | нет | нужен текст на 150-200 слов без финала |
| Полный синопсис | нет | нужен текст на 600-800 слов с финалом для издателя |
| Питч-док | нет | нужна отдельная печатная страница |
| Аннотации изданий | по одной строке | расширить до 60-90 слов |
| Аннотации частей | по одной строке | расширить до 40-60 слов |
| Обзор мира | нет | каталоги есть, связного введения нет |
| Печатная версия | нет | нужен A4-вариант без шапки, звука и неона |

### 5.2. Расхождения

1. В промо-текстах стоял «приказ, подписанный её рукой». В каноне это «передача материалов Z-9». Для логлайна и аннотации выбрана формулировка «документ, подписанный её рукой», чтобы не терять крючок и не спорить с каноном.
2. Главная книга имела статус «издан», хотя готовы 23 главы из 34. Для питча принят статус «рукопись, 23 из 34 глав».
3. В `docs/site/README.md` указаны 22 маршрута и 50 проверок, в `tools/README.md` 23 маршрута и 105 мобильных проверок. Фактически до добавления питча было 26 маршрутов, 52 проверки QA и 130 мобильных проверок.
4. Страница мира начинается с разреза города и каталогов, но не объясняет, как город живёт, кто им управляет и почему воздух стал услугой.
5. Страница книги не показывает логлайн и короткий синопсис до содержания.
6. Страница автора не имеет блока для издателей.
7. Поиск не знает о питче и логлайне.

## 11. Риски

1. Полный синопсис опирается на планы глав 24-34, а не на готовый текст. Если планы изменятся, синопсис придётся обновить.
2. Питч и сайт могут разойтись по статусу, если позже снова написать «издан».
3. Длинный синопсис на мобильном может стать тяжёлым, нужен спокойный ритм и ограничение ширины.
4. Печать может захватить лишние элементы, если не скрыть шапку, подвал, поиск и звук.
5. Новый маршрут нужно добавить в QA, mobile и обход ссылок, иначе проверки будут неполными.
