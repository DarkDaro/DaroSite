## Что это за проект

Локальный артбук-архив романа «Соляной протокол». Открывается через `C:\Site\index.html` без сервера, сборки и интернета. Runtime на обычных HTML, CSS и JS. Внешних CDN и запросов нет.

## Главные правила

- Активная тема: киберпанк-нуар с неоном. Бетонную и соляную темы не возвращать без согласования.
- Node используется для инструментов. Python в проекте не использовать.
- Не добавлять React, Vite, CDN и внешние runtime-запросы.
- Не использовать длинное тире и эмодзи.
- Мобильный адаптив проверять на 320, 360, 390, 430 и 768 px.
- Не удалять неактуальные файлы. Переносить в `C:\Site\archive\` и обновлять `archive/README.md`.
- `archive/` и `docs/solyanoy-protocol/drafts/` не входят в Git.
- Git только через терминал. Push только по отдельной просьбе.
- Больше не применять antislop к дизайну. Сайт считается стилевым и законченным.
