## 1. Структурный проход

- [ ] Три акта: 1-11, 12-23, 24-34.
- [ ] Первый поворот в главе 11: свидетель называет Марка.
- [ ] Второй поворот в главе 19: Марк показывает подпись Киры.
- [ ] Третий поворот в главе 33: Соляной человек отдаёт антитело.
- [ ] Кира принимает решения, а не только бежит.
- [ ] Марк действует по своему плану с первой главы.
- [ ] Хан меняет сторону не случайно, а после приказа Марка.
- [ ] Ада погибает после собственного выбора, а не для мотивации Киры.
- [ ] Финал закрывает историю города и оставляет открытой сеть покупателей.
- [ ] Ни одна глава не повторяет функцию соседней.

**Что не делать:** не менять финал, пока не проверена причинность. Не добавлять новые сцены, пока не вырезаны лишние.

## 2. Сценический проход

- [ ] В каждой главе есть цель, препятствие и изменение.
- [ ] Сцена начинается поздно и заканчивается рано.
- [ ] В погоне есть цена: ранение, потеря, ошибка.
- [ ] В разговоре есть подтекст, а не только информация.
- [ ] В каждой главе есть конкретное место и время.
- [ ] Нет двух глав подряд, где Кира только получает информацию.
- [ ] Нет сцен, где персонажи объясняют то, что читатель уже знает.
- [ ] Каждая глава заканчивается крючком, а не паузой.

## 3. Персонажный проход

- [ ] Кира хочет остановить протокол и хочет не быть виновной.
- [ ] Кира ошибается: сначала думает, что её подставили.
- [ ] Кира признаёт подпись в главе 31 и не получает прощения.
- [ ] Марк не злодей ради злодейства: он считает, что дозирует город.
- [ ] Хан не карикатура: у него есть семья, приказ и стыд.
- [ ] Ада не только источник: у неё есть свой выбор и цена.
- [ ] Нора не только проводник: у неё брат и долг.
- [ ] Тэо не только техник: у него братья и страх.
- [ ] Ли не святой: он скрывал правду о Z-9.
- [ ] Йона не маскот: она ребёнок, который выбирает помочь.
- [ ] Соляной человек не появляется как внезапное спасение: он человек с ценой.
- [ ] Веспер не бог: он свидетель с ограничениями.

## 4. Проход мира

- [ ] Верхний ярус имеет отдельный контур воды и воздуха.

- [ ] «Полотно» не всевидящее: есть швы и слепые зоны.
