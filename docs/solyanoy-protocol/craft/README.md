# Craft: Соляной протокол

Версия: 0.1
Дата: 2026-10-24
Назначение: рабочая папка по структуре глав и арок
Статус: вспомогательный слой, не канон

> Это не замена `chapter-plan.md` и не новый канон. Здесь лежат инструменты, которые помогают проверять главы и планировать оставшиеся фабулы.

## Порядок чтения

1. `harmon-circles.md` - как работает круг, пять узлов главы, арки, глобальный конфликт, ограничения.
2. `templates/chapter-spine.md` - быстрый позвоночник главы.
3. `templates/chapter-circle.md` - полный круг для поворотной главы или финала акта.
4. `templates/scene-micro-circle.md` - четыре такта для ключевой сцены.
5. `templates/arc-matrix.md` - матрица арок, передач хода, столкновений и зеркал.
6. `templates/faction-circle.md` - круг фракции для глобального конфликта.
7. `templates/checklist.md` - 12 вопросов к готовой главе.
8. `demos/` - три внешних примера: полный, отрицательный и частичный круг.
9. `circle-grid-9-34.md` - сетка оставшихся глав и аудит.

## Главное правило

Полный круг для акта и арки. Пять узлов для главы. Четыре такта для сцены. Восемь шагов в каждой главе не нужны.

## Что здесь не делать

- Не переписывать готовые главы 1-8 под схему.
- Не заполнять неизвестные клетки выдуманными деталями. Если канон не отвечает, ставить `?`.
- Не менять `chapter-plan.md` через эти файлы. Сетка живёт отдельно.
- Не использовать круг как доказательство качества. Он показывает движение персонажа, а не голос, атмосферу и детали.
