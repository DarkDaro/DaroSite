# Учебный комплект: круги Хармона

Версия: 0.2
Дата: 2026-10-24
Назначение: демонстрация и обучение автора
Статус: учебный материал, не аудит проекта

> Это учебный комплект. Он показывает, как работает круг Хармона, и даёт шаблоны для упражнений. Он не проверяет главы «Соляного протокола», не оценивает канон и не заменяет редактуру.

## Порядок чтения

1. `harmon-circles.md` - как работает круг, пять узлов главы, арки, глобальный конфликт, ограничения.
2. `templates/chapter-spine.md` - быстрый позвоночник главы.
3. `templates/chapter-circle.md` - полный круг для разбора поворотной главы или финала акта.
4. `templates/scene-micro-circle.md` - четыре такта для ключевой сцены.
5. `templates/arc-matrix.md` - матрица арок, передач хода, столкновений и зеркал.
6. `templates/faction-circle.md` - круг фракции для глобального конфликта.
7. `templates/checklist.md` - вопросы для разбора, не оценка.
8. `demos/` - три внешних примера: полный, отрицательный и частичный круг.

В конце `harmon-circles.md` есть шесть упражнений. Комплект можно использовать на любом материале: фильм, повесть, учебная сцена.

## Главное правило

Полный круг для акта и арки. Пять узлов для главы. Четыре такта для сцены. Восемь шагов в каждой главе не нужны.

## Что здесь не делать

- Не прогонять историю на сайте по кругу и не строить аудит глав.
- Не переписывать главы 1-8 под схему.
- Не заполнять неизвестные клетки выдуманными деталями. Если канон не отвечает, ставить `?`.
- Не считать круг обязательной сеткой или доказательством качества.
- Не превращать учебный разбор в оценку автора.

## Опционально

`optional/applied-grid-9-34.md` - прикладной эксперимент. Это не часть учебного комплекта, а пример того, как выглядит сетка, если приложить круг к конкретному проекту. Можно не читать.
