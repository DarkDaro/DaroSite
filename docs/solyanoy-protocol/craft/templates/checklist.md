# Чек-лист главы

## Круг

- [ ] У POV есть конкретное желание?
- [ ] Желание проверяется действием, а не мыслью?
- [ ] Есть событие, которое выбивает его из порядка?
- [ ] Есть две-три попытки, а не одна?
- [ ] Есть ложная победа или частичный успех?
- [ ] Платит именно POV?
- [ ] Цена видна в действии, а не только в мыслях?
- [ ] Есть возврат к знакомому месту, роли или мотиву?
- [ ] Изменение видно в следующей главе?
- [ ] Глава меняет условия для следующей?
- [ ] Глава двигает арку персонажа, а не только сюжет?
- [ ] Глава не повторяет форму предыдущей?

## Быстрая проверка

Если ответов «да» меньше восьми, глава, вероятно, держится на событиях, а не на движении персонажа.

Если нет «Плачу», это может быть мостовая глава. Тогда пометь её как мост и проверь, что она меняет в знании или настроении.

Если нет «Выхожу другим», глава может быть эпизодом. Это допустимо, но не для поворотной главы и не для финала акта.
