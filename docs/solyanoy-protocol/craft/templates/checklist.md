# Вопросы для разбора

Это вопросы для обучения и разбора примеров, не оценка главы и не приговор автору.

## Круг

- [ ] У POV есть конкретное желание?
- [ ] Желание проверяется действием, а не мыслью?
- [ ] Есть событие, которое выбивает его из порядка?
- [ ] Есть две-три попытки, а не одна?
- [ ] Есть ложная победа или частичный успех?
- [ ] Платит именно POV?
- [ ] Цена видна в действии, а не только в мыслях?
- [ ] Есть возврат к знакомому месту, роли или мотиву?
- [ ] Изменение видно в следующей главе?
- [ ] Глава меняет условия для следующей?
- [ ] Глава двигает арку персонажа, а не только сюжет?
- [ ] Глава не повторяет форму предыдущей?

## Как использовать

Если ответов «да» меньше восьми, разбор показывает, что глава держится на событиях, а не на движении персонажа. Это наблюдение, не приговор.

Если нет «Плачу», возможно, перед тобой мостовая глава. Тогда посмотри, что она меняет в знании или настроении.

Если нет «Выхожу другим», глава может быть эпизодом. Это допустимо, но полезно понимать, зачем он нужен.

Эти вопросы можно задавать чужому фильму, чужой главе и своему черновику. В последнем случае они не требуют немедленной правки.
