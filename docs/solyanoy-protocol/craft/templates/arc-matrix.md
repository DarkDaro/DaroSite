## 3. Столкновения

## 4. Зеркала

|  |  |  |  |  |  |

## 5. Ансамбль

| Персонаж | Полный круг | Микрокруги | Главы | Что нельзя потерять |
|---|---|---|---|---|
|  |  |  |  |  |

## Правила

- Полный круг даётся трём-четырём главным персонажам.
- Остальные получают микрокруги и столкновения.
- Каждый крупный персонаж должен хотеть чего-то, что не связано с протагонистом.
- Если персонаж исчезает больше чем на четыре главы, его арка остывает.
- Если два персонажа хотят одного и того же, их шаг 5 не может случиться одновременно.
