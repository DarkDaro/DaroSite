## Одна фраза

> Герой хочет X. Дверь Y выбивает его из порядка. Он ищет Z, получает X, платит P, возвращается в Q и теперь делает R.

## Пять узлов

| Узел | Ответ | Проверка |
|---|---|---|
| Хочу |  | Цель конкретная и проверяемая? |
| Дверь |  | Событие нельзя игнорировать? |
| Ищу |  | Две-три попытки с разной ценой? |
| Плачу |  | Платит именно POV? |
| Выхожу другим |  | Что он делает иначе? |

## Попытки

| Попытка | Что делает | Что получает | Чем платит |
|---|---|---|---|
| 1 |  |  |  |
| 2 |  |  |  |
| 3 |  |  |  |

## Проверка

- [ ] Если не заполняется «Плачу», глава, вероятно, эпизод, а не круг.
- [ ] Если не заполняется «Выхожу другим», глава не меняет условия для следующей.
- [ ] Если все три попытки одинаковые, поиск выглядит как монтаж.
