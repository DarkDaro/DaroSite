## 2. Правила именования

- Одно имя, одно написание. Без вариантов через дефис и без «например».
- Имена персонажей не должны отличаться одной буквой, если читатель должен их различать.
- Имена не должны случайно совпадать с известными брендами, реальными политиками или чужими персонажами.
- В одном языке одна фонетика. Если язык другой, это должно быть видно.
- Термин получает заглавную букву только если это официальное название.
- Сокращения расшифровываются при первом появлении.
- Для русской прозы проверяйте склонение, ударение и родовую форму.
- Не используйте имена, которые нельзя произнести вслух с первого раза.
- Не используйте одинаковые титулы для разных культур без объяснения.
- Если имя меняется по политическим причинам, это фиксируется в `retcon-log.md`.

## 4. Запрещено

- Два имени с одинаковой первой буквой и одинаковым ритмом.
- Имена, которые звучат как шутка, если шутка не нужна.
- Термины, которые объясняются после первого использования.
- Названия, которые меняются в зависимости от POV без причины.
- Реальные торговые марки и имена без необходимости.
- Эмодзи и декоративные символы в именах.
- Случайные апострофы для «инопланетности».
- Диакритика, которую читатель не сможет набрать.
