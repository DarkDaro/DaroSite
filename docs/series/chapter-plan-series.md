## 7. Проверка главы

- [ ] Глава двигает основную линию книги.
- [ ] Глава двигает хотя бы одну линию серии.
- [ ] Глава меняет персонажа, отношение или знание.
- [ ] У POV есть цель, а не только наблюдение.
- [ ] Антагонист действует по своему плану.
- [ ] В главе есть цена, а не только информация.
- [ ] Улика или отдача работают на будущее.
- [ ] Нет двух глав одного типа подряд без намерения.
- [ ] Нет сцены, которую можно вырезать без потерь.
- [ ] Выход тянет дальше, но не обрывает главу на пустом месте.

## 8. Проверка книги

- [ ] Первая глава обещает то, что книга действительно даёт.
- [ ] Середина книги не только готовит финал.
- [ ] Финал книги отвечает на вопрос книги.
- [ ] Последняя глава оставляет новую дверь, а не обрыв.
- [ ] Вторая книга не повторяет структуру первой.
- [ ] Третья книга платит за обещания первых двух.
