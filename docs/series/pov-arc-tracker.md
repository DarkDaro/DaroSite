## 7. POV-правила

- [ ] У каждого POV есть цель в каждой сцене.
- [ ] POV не знает того, чего не может знать.
- [ ] POV не исчезает без следа.
- [ ] POV не появляется только чтобы объяснить мир.
- [ ] POV не дублирует функцию другого POV.
- [ ] Переходы между POV не сбивают время и место.
- [ ] В каждой книге есть POV, который меняет главный герой.
- [ ] В каждой книге есть POV, который меняет читатель.

## 8. Проверка арок

- [ ] Герой делает выбор, а не только реагирует.
- [ ] Цена выбора видна в следующей главе.
- [ ] Изменение необратимо.
- [ ] Вторая книга не обнуляет первую.
- [ ] Третья книга платит за первые две.
- [ ] Второстепенные персонажи не застывают.
- [ ] Антагонист меняется или раскрывается.
- [ ] Финал не делает арки бессмысленными.
