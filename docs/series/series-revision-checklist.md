## 1. Дуга серии

- [ ] Главный вопрос серии сформулирован.
- [ ] Ответ на него есть в финале.
- [ ] Первая книга обещает то, что серия действительно даёт.
- [ ] Вторая книга усложняет, а не повторяет.
- [ ] Третья книга платит за обещания первых двух.
- [ ] Ставка растёт от книги к книге.
- [ ] Цена становится конкретнее.
- [ ] Финал меняет мир, а не только настроение героя.
- [ ] Серия не заканчивается на новом вопросе вместо ответа.

## 2. Книги

- [ ] У каждой книги есть собственная цель.
- [ ] У каждой книги есть собственный антагонист или препятствие.
- [ ] У каждой книги есть финал.
- [ ] Вторая книга не является мостом.
- [ ] Третья книга не начинается с обнуления.

- [ ] Выход из каждой книги меняет состояние мира.
- [ ] Нет книги, которую можно пропустить без потерь.

## 3. POV и персонажи

- [ ] У каждого POV есть цель.
- [ ] POV не дублируют друг друга.
- [ ] POV не исчезают без следа.
- [ ] Главный герой принимает решения.
- [ ] Антагонист действует по своему плану.
- [ ] Второстепенные персонажи меняются.
- [ ] Смерти меняют оставшихся.
- [ ] Новые персонажи не появляются только чтобы умереть.
- [ ] Арки не обнуляются между книгами.
- [ ] Финал не делает арки бессмысленными.

## 4. Мир и технологии

- [ ] Правила мира не меняются ради сцены.
- [ ] Технология имеет цену.
- [ ] Технология имеет предел.
- [ ] Технология имеет сбой.
- [ ] Технология имеет контрмеру.
- [ ] Технология меняет общество, а не только сцену.
- [ ] Новая версия не отменяет старую без последствий.
- [ ] Герой не получает решение в последней главе.
- [ ] Антагонист не получает технологию без объяснения.
- [ ] Научные допущения не противоречат друг другу.

- [ ] Ответ не появляется из ниоткуда.
- [ ] Читатель мог догадаться.

- [ ] Ложные следы честные.
- [ ] Раскрытие меняет ставку.
- [ ] Одна книга закрывает хотя бы одну важную тайну.
- [ ] Открытые линии не забыты.
- [ ] Нет линии, которая держится только на молчании.
- [ ] Финал отвечает на главный вопрос серии.

- [ ] Противоречия закрыты или объяснены.
