# Архив сайта и романа

Версия: 0.1
Дата: 2026-10-24
Назначение: хранить неактуальные версии файлов, чтобы ничего не удалять и не терять историю правок.

## Правило

- Не удалять неактуальные файлы, темы, данные и тексты.
- Переносить их в `C:\Site\archive\` с датой и понятным именем.
- Активные файлы в архиве не лежат. Архив только для истории.
- После переноса обновить ссылки в `docs/site/README.md` и в этом индексе.
- Из архива ничего не удалять без явного разрешения пользователя.
- Если файл нужен для проверки или отката, сначала копировать, потом менять активную версию.

## Структура

| Папка | Что хранит |
|---|---|
| `themes/` | Старые темы и снимки `main.css` |
| `data/` | Старые версии `data.js` и `app.js` |
| `chapters/` | Старые полные тексты глав |
| `docs/` | Устаревшие внутренние документы |

## Как добавить файл

1. Определите, почему файл больше не активен.
2. Выберите папку: `themes`, `data`, `chapters` или новую по смыслу.
3. Скопируйте или перенесите файл с датой в имени, если имя неочевидное.
4. Добавьте строку в индекс: дата, путь, что это, причина.
5. Обновите ссылки в `docs/site/README.md`.
6. Проверьте, что активная версия файла не попала в архив.

## Связь с глобальным правилом

Общее правило проекта: не удалять без явной просьбы. Если файл устарел, он переезжает сюда, а не исчезает. Это касается тем, данных, глав, шаблонов и служебных документов.
