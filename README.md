# Соляной протокол

Локальный артбук-архив романа «Соляной протокол». Мрачный биотех-детектив о городе Кассий, корпоративном дожде и биологическом агенте «Соль-7».

Сайт открывается напрямую через `index.html`. Сервер, установка, интернет и внешние библиотеки не нужны. Это не магазин и не промо-лендинг: здесь нет цен, покупок, подписок, отзывов, аналитики и счётчиков.

## Что внутри

- Библиотека книг и материалов.
- Книга с тремя частями и 34 главами.
- Читалка. На сайте опубликованы главы 1-23. Главы 24-34 открыты как карточки с синопсисами.
- Мир: персонажи, локации, организации, имплантаты, вооружение, хронология и словарь.
- Архивные документы: передача Z-9, протокол, накладная, радиоперехват, допрос Норы, протокол совета, список покупателей, медкарта, приказ на зачистку, схема впрыска, пропускной журнал КПП и журнал фильтров.
- Галерея пластин.
- Страница автора и устройство архива.
- Кнопка «Наверх» на всех страницах: справа внизу, появляется после 400 px прокрутки.
- Неоновые CSS-эффекты: скан, появление блоков, подъём карточек, анимация меню и пластин.
- Параллакс обложки, мягкие переходы между страницами и липкий прогресс чтения.
- Музыка с отдельной темой для крупных разделов, звуковые эффекты и экспериментальная озвучка глав и досье. Кнопка «Звук» в шапке выключает всё сразу, общая громкость регулируется ползунком в настройках звука.

## Как открыть

1. Откройте `C:\Site\index.html` в браузере.
2. Переходите по разделам через верхнее меню.
3. Для чтения полной главы выберите «Главы» или «Читать первую главу».

Для локальной проверки можно поднять сервер на Node:

```powershell
npm run serve
```

Затем открыть `http://127.0.0.1:8765/`. Node нужен только для проверок и сервера, сам сайт работает без него.

## Как проверить звук

1. Откройте `about.html`, `http://127.0.0.1:8765/about.html` или нажмите «Настройки звука» в подвале.
2. Прокрутите до блока «Музыка, эффекты и озвучка».
3. Ползунок «Громкость» задаёт общий уровень музыки, эффектов и голоса. По умолчанию 70 процентов, значение запоминается.
4. Нажмите «Проверить музыку», «Проверить эффект», «Проверить голос». «Проверить музыку» начинает текущую тему с нуля, чтобы услышать интро.
5. Кнопка «Звук» в шапке выключает и включает всё сразу. Выбор запоминается.
6. На странице главы нажмите «Озвучить». В досье тоже есть кнопка «Озвучить».

Темы длятся 48 секунд, начинаются и заканчиваются плавным фейдом, поэтому зацикливаются без клика. Пересборка: `npm run music`, нужен `ffmpeg` с `libmp3lame`.

Браузер не включает звук до первого клика. Если музыки не слышно, нажмите «Звук» в шапке или кликните по странице. Если голос звучит не по-русски, в Windows не установлен русский голос, и сайт использует системный.

## Данные и правки

`assets/js/data.js` это источник истины для контента. HTML-страницы содержат только оболочку, а тексты, досье, главы и галерея собираются из данных.

После правки проверяйте синтаксис:

```powershell
node --check assets/js/data.js
node --check assets/js/app.js
```

Основные правила:

- Не добавлять внешние запросы, CDN, аналитику и сторонние шрифты.
- Шрифты, изображения и поиск остаются локальными.
- Не использовать длинное тире, эмодзи и рекламные обороты.
- Активная тема сайта: киберпанк-нуар с неоном. Не заменять её на бетонную или бумажную без отдельного решения.
- Не удалять неактуальные файлы. Переносить их в `archive/` и фиксировать в `archive/README.md`.

## Git

Репозиторий инициализирован в `C:\Site`, ветка `main`. Последний коммит: см. `git log -1`.

- `.gitignore` исключает временные файлы, кэши, секреты и служебные папки.
- `.gitattributes` задаёт LF для текста и `binary` для изображений, шрифтов и аудио.
- Ассеты, шрифты, шаблоны и основная документация остаются в репозитории.
- Рабочие черновики в `docs/solyanoy-protocol/drafts/` исключены из Git.
- `archive/` остаётся на диске, но не попадает в Git. Это локальная история версий.

## Изображения и лицензии

Изображения лежат локально в `assets/art/` в WebP-вариантах. Авторы, лицензии и ссылки на оригиналы указаны в галерее и на странице автора. Внешние ссылки открываются только по нажатию и не создают runtime-запросов.
